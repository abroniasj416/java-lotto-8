# java-lotto-precourse

## 기능 목록

- 에러 발생 시 재입력 받는 기능
- 프로그램 전체 흐름을 통제하는 기능

- 로또 구입 금액을 입력받는 기능
- 당첨 번호를 입력받는 기능
- 입력받은 당첨 번호 문자열(쉼표 구분)을 파싱하여 6개의 메인 번호를 생성하는 기능
- 보너스 번호를 입력받는 기능

- 구입 금액만큼 로또 발행 수를 계산하는 기능
- 로또 1장을 발행하는 기능
- 로또 N장을 발행하는 기능

- 발행 수를 출력하는 기능
- 발행한 로또 번호를 출력하는 기능
- 당첨 통계 및 총 수익률을 출력하는 기능

- 한 장의 로또 번호 6개를 관리하는 기능
- 로또 번호의 유효성을 검증하는 기능 (개수 6개, 범위 1~45, 중복 없음)
- 로또 번호를 오름차순으로 정렬하는 기능

- 당첨 번호와 보너스 번호의 유효성을 검증하는 기능 (범위, 중복 포함)

- 구매한 로또 번호와 당첨 번호를 비교하여 등수를 판정하는 기능

- 등수별 집계를 수행하는 기능
- 총 수익률을 계산하는 기능

---

## 예외 처리 목록

> 모든 에러 문구는 `[ERROR]` 로 시작해야 함

- 번호가 정확히 6개인지 검증하는 기능
- 번호가 1~45 범위 내에 있는지 검증하는 기능
- 번호의 중복 여부를 검증하는 기능
- 구입 금액이 1,000원으로 나누어 떨어지는지 검증하는 기능
- 구입 금액이나 당첨 번호 입력에 숫자가 아닌 값이 들어왔는지 검증하는 기능
- 당첨 번호가 쉼표(,)로 올바르게 구분되어 있는지 검증하는 기능
- 보너스 번호가 1~45 범위 내에 있는지 검증하는 기능
- 보너스 번호가 당첨 번호와 중복되지 않는지 검증하는 기능
- 입력이 비어있거나 공백만 있는 경우를 검증하는 기능
