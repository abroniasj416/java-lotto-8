# java-lotto-precourse

# 로또 프로그램 기능 및 예외 목록

## 기능 목록

- **로또 구입 금액을 입력받는 기능**  
  → `"구입금액을 입력해 주세요."`

- **로또 구입 금액만큼의 로또 발행 수를 구하는 기능**  
  → `"n개를 구매했습니다."`

- **로또 번호 6개를 뽑는 기능**

- **발행한 로또를 출력하는 기능**  
  → `n번` 반복 출력

- **당첨 번호를 입력받는 기능**  
  → `"당첨 번호를 입력해 주세요."`

- **입력받은 당첨 번호를 쉼표(,)를 기준으로 구분하는 기능**

- **보너스 번호를 입력받는 기능**  
  → `"보너스 번호를 입력해 주세요."`

- **구매한 로또 번호와 당첨 번호를 비교하는 기능**

- **수익률을 계산하는 기능**

- **당첨 내역 및 수익률을 출력하는 기능**  
  → `"당첨 통계"`, `"총 수익률은 --- %입니다."`

---

## 예외 목록

> 예외 상황 발생 시 에러 문구를 출력해야 한다.  
> 모든 에러 문구는 **`[ERROR]`** 로 시작해야 한다.

- 로또 번호의 숫자 범위가 **1~45** 사이인가?
- 로또 발행 시 **6개의 숫자가 중복되지 않는가?**
- 구입 금액이 **1,000원으로 나누어 떨어지는가?**
- 당첨 번호를 **쉼표(,)** 를 기준으로 올바르게 입력했는가?
